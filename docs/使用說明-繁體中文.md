# P-Scan Defect 1.5.1 — 使用說明

發行者：Agent-QW1427

## 初次使用

請完整結束舊版，再將新版解壓縮至新資料夾並開啟 EXE。程式沿用 `%APPDATA%\P-Scan-Defect-ID`，因此既有設定與歷史紀錄保留；請勿同時開啟兩個版本。此版本不會自動翻譯已儲存的舊紀錄。

1. 選擇輸入資料夾與 Good、NG-Defect 輸出資料夾。三個位置必須分開。
2. 先使用「測試：記錄結果，不複製影像」。測試原始影像，不使用圈選標記後的副本。
3. 按「測試影像／預覽」，檢查綠色實線、D 缺陷框及 T 待複核框。
4. 確認後勾選校準同意，儲存設定，再切換自動模式並開始背景掃描。

只有文字與發行資訊變更，檢測引擎版本仍為 1.5；原本有效的校準設定可沿用，仍建議用已知 Good 與 NG 樣本確認。

## 判定與圖示

- Good：在成功檢測的焊墊內部未發現缺陷。焊墊數量不符或被裁切，不會單獨阻止 Good；結果會註記部分檢測。
- 被裁切焊墊：略過其內部檢測，不代表已確認整個焊墊良好。
- NG-Defect：已確認的斑點，或通過大型深色污點驗證。其他區域不完整時仍可判定 NG。
- 待複核：邊界不明、T 候選、黃色標記遮蔽或沒有可檢測的焊墊等情形。
- 大型深色污點：至少需要 3 個完整、已驗證的周圍焊墊；僅深色／混合模式生效。此功能可能漏檢或誤判，需使用實際樣本驗證。
- PR 殘留未檢測；本版未導入 PatchCore。

## 重新檢測同一批影像

按暫停並等待目前處理完成，視需要先匯出 CSV，再按「重設歷史紀錄」並確認。這會刪除紀錄、預覽、計數及已處理標記，但保留原始影像、設定與輸出檔案。按開始即可重新檢測。

如果調整參數後分類可能改變，使用新的輸出資料夾，避免舊檔案引發分類衝突。已有相同內容的檔案不會重複覆寫。

## 語言與資料格式

介面、提示、錯誤、系統匣、檢測描述及 CSV 欄名使用繁體中文；日期使用 zh-TW。Good、NG-Defect、D、T、技術欄位與資料夾名稱保留，避免破壞既有流程。CSV 為含 BOM 的 UTF-8。系統原生對話框部分文字依 Windows 的語言顯示。
